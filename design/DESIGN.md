## 1. Концепция

Путевая тетрадь на васи. Страница — небелёная бумага, текст — тушь, и одна красная печать-ханко. Дух взят у noetx.com (тёплая бумага `#f8f6f0`, чернила в четыре ступени, serif для чтения, почти нулевые радиусы, «цитата — не карточка»), бренд — нет: ни имени, ни логотипа.

Пять правил, на которых всё держится:

1. **Бумага, а не панели.** Фраза — запись на странице, отделённая волосной линией. Листом (белая поверхность, тонкая тень) становится только то, что «подняли»: раскрытая фраза, карточка для повторения, квиз.
2. **Тушь — главное действие.** Основная кнопка чёрная (суми), а не красная. Красный оставлен печати.
3. **Одна печать.** Киноварь (сю) встречается на экране 2–3 раза: штамп активной вкладки, точка после заголовка, звезда избранного, номера экстренных служб. Больше нигде.
4. **Ма — пустота как материал.** Поля страницы 20 px, между разделами 32 px, заголовок раздела — капитель с линейкой, а не плашка.
5. **Четыре голоса шрифта.** Японский — минчо; как произнести (ромадзи) — прямой гротеск; что это значит (русский) — антиква с кириллицей; интерфейс — системный гротеск. Их нельзя перепутать даже боковым зрением.

Японские мотивы, которые несут смысл, а не украшают:

| Мотив | Где | Зачем |
|---|---|---|
| Ханко (печать) | активная вкладка, иконка приложения, `.seal` | «вы здесь», «сделано» |
| Гэнко-ёси (разлинованная рукописная бумага) | таблица каны `.kgrid5` | сетка без коробок, линии с примесью киновари |
| Прописной квадрат с крестом | знак в квизе `.kana-big` | как в детских прописях |
| Мару ○ / бацу × | верно / неверно | состояние читается без цвета |
| Энсо (незамкнутый круг) | пустое состояние, загрузка | пустота, а не ошибка |
| Синяя линейка на поле | фразы персонала `.phrase.hear` | «это скажут вам» — как цитата |

### Карточка «показать японцу»

Белая бумага `#ffffff`, чёрная тушь `#000000` (21:1) **в обеих темах** — токены `--show-*` не переопределяются. Подпись для себя `#555555` (7.46).

### Темы и переключатель

- По умолчанию светлая. Тёмная включается сама по `prefers-color-scheme: dark`, если пользователь не выбрал тему вручную.
- Ручной выбор — атрибут на `<html>`: `data-theme="light"` или `data-theme="dark"`. Без атрибута — «как в системе».
- Блок тёмной темы в `tokens.css` записан дважды (медиа-запрос и атрибут) — это цена чистого CSS; значения должны совпадать.

```js
// раньше первого кадра, в <head>:
const t = localStorage.getItem('theme'); if (t) document.documentElement.dataset.theme = t;
// кнопка <button class="theme-toggle" aria-label="Тема">:
btn.onclick = () => {
  const el = document.documentElement;
  const dark = el.dataset.theme ? el.dataset.theme === 'dark' : matchMedia('(prefers-color-scheme: dark)').matches;
  el.dataset.theme = dark ? 'light' : 'dark';
  localStorage.setItem('theme', el.dataset.theme);
  document.querySelector('meta[name=theme-color]').content = dark ? '#f5f1e7' : '#171613';
};
```

В `index.html`: `<meta name="color-scheme" content="light dark">` и два `theme-color` (`#f5f1e7` с `media="(prefers-color-scheme: light)"`, `#171613` — dark). В манифесте: `background_color` и `theme_color` = `#f5f1e7`.

### Фактура бумаги

Два крошечных инлайновых SVG-шума (`feTurbulence`) в `--paper-grain` (мелкое зерно, плитка 240 px) и `--paper-fibre` (мягкая неровность тона, плитка 480×320). Вместе около 0.7 КБ текста в CSS, ни одной картинки. Лежат на `body`; листы (`--surface`) — гладкие, поэтому отделяются от страницы без тяжёлой тени. Браузер растрирует плитку один раз, прокрутку это не замедляет (фон не `fixed`).

## 3. Шрифты

### Четыре роли

| Роль | Токен | Шрифт | Где |
|---|---|---|---|
| Японский, крупный | `--font-ja-display` | **Shippori Mincho 500** (свой сабсет) → Hiragino Mincho ProN (iOS) → Noto Serif CJK JP (Android) → Yu Mincho | фраза, кана, кандзи, знак в печати |
| Японский, мелкий | `--font-ja-ui` | системный готик: Hiragino Sans (iOS), Noto Sans CJK JP (Android) | фуригана, чтения в шпаргалке, японский в заметках, карточка «показать» |
| Русский для чтения | `--font-read` | **Lora** (свой сабсет, вариативный 400–700) → Georgia | перевод, заголовки, номера |
| Интерфейс и ромадзи | `--font-ui` | системный: Roboto (Pixel), SF (iPhone) | кнопки, подписи, ромадзи, числа |

Почему так: минчо на 22–36 px красив и читаем, а на 10–13 px его тонкие штрихи рассыпаются — поэтому всё мелкое японское идёт готиком. Карточка «показать» — жирный готик: японцу с метра он читается быстрее минчо, и системный шрифт покрывает любой текст, вставленный из Переводчика.

### Офлайн и размеры (измерено)

CJK-шрифт целиком — 8.7 МБ на одно начертание (исходники лежат в `fonts/src/`, в деплой не идут). В приложение идут три файла:

| Файл | Что внутри | Размер |
|---|---|---|
| `fonts/shippori-mincho-500.kana.woff2` | хирагана, катакана, японская пунктуация, полноширинные знаки, цифры — 305 глифов | **43 КБ** |
| `fonts/shippori-mincho-500.kanji.woff2` | только кандзи, которые есть в данных приложения и PLAN.md — сейчас 361 | **66 КБ** |
| `fonts/lora-var.woff2` | латиница, ō ū ē ā ī, кириллица, пунктуация — 320 глифов, ось wght 400–700 | **47 КБ** |
| `fonts/fonts.css` | три `@font-face` с `unicode-range` (генерируется) | 4 КБ |

Итого около **156 КБ** против ~17 МБ за два полных начертания. Лицензии SIL OFL 1.1: `fonts/LICENSE-ShipporiMincho-OFL.txt`, `fonts/LICENSE-Lora-OFL.txt`.

Что будет, если шрифт не загрузился или знака нет в сабсете: `font-display: swap` и `unicode-range` — браузер молча берёт системный минчо для отсутствующего знака. Это штатное поведение, а не ошибка: свободный текст пользователя и новые фразы всегда отобразятся. Чтобы новые кандзи тоже были в фирменном минчо, после правки `data/*.json` перезапустить:

```
design/tools/.venv/Scripts/python design/tools/subset-fonts.py
```

Скрипт читает `app/**/*.json|js|html`, `PLAN.md` и макет (только чтение), пишет три woff2 и `fonts.css`. Venv локальный (`fonttools`, `brotli`, `pillow`), системного ПО не требует.

Внешних CDN нет. Необязательная альтернатива, если захочется готик вместо системного: Noto Sans JP с Google Fonts — около 1.1–1.6 МБ на начертание в woff2-сабсетах, офлайн только после полного кеширования; **не рекомендую**.

### Фуригана и ромадзи

- Разметка: `<ruby>袋<rp>(</rp><rt>ふくろ</rt><rp>)</rp></ruby>` — ровно то, что уже делает `rubyEl()`.
- `rt`: системный готик, 0.46em от основы (10 px при 22, 12 px при 26), цвет `--ink-3`, не выделяется при копировании. `rp` скрыт.
- Ромадзи: прямой (не курсив) системный гротеск 15 px, `--ink-2`, лёгкая разрядка. Это строка, которую человек читает вслух у кассы, — она не должна быть серой и мелкой. Макроны ō ū есть и в системных шрифтах, и в Lora.

## 4. Размеры, касание, safe area

- Минимальная цель касания `--tap: 48px` (кнопки, круглые ▶ / 0.7× / показать / ★, строки чекбоксов, вкладки). Главные действия — `--tap-lg: 56px` (`.btn.big`, оценки карточки, варианты квиза).
- Чипы высотой 44 px и `.btn.small` 36 px добирают до 48 px невидимым ореолом (`::before`).
- Таб-бар 64 px + `env(safe-area-inset-bottom)`; всё важное — в нижних двух третях экрана: ▶ слева под большим пальцем, «показать» и ★ справа.
- Поля страницы 20 px плюс `safe-area-inset-left/right` (альбомная ориентация iPhone).
- `viewport-fit=cover` уже стоит; `#view` и `.fs` учитывают верхний inset (установленная PWA на iPhone).
- Ширина контента до 560 px, на планшете шпаргалка в 3 колонки, плитки в 4.

### Фразы
```html
<article class="phrase [hear] [is-collapsed | open]">
  <div class="badge">Вы услышите</div>          <!-- или .badge.pat с шаблоном -->
  <div class="jp"><span class="ja" lang="ja">…ruby…</span></div>
  <div class="romaji">fukuro wa irimasen</div>
  <div class="ru">Пакет не нужен</div>
```

- Без модификаторов (как сейчас) — всё видно, записи разделены линией (`shots/phrases-flat-*`).
- **[NEW]** `.is-collapsed` прячет заметку и кнопки, `.open` поднимает фразу листом и укрупняет японский до 26 px. Рекомендую: в списке все свёрнуты, тап раскрывает одну (`shots/phrases-*`, `shots/phrase-open-*`). Экран вмещает 5–6 фраз вместо 3.

- **[NEW]** `.kana-line` — строка чтения каной под крупным японским.

### Показать
- Список: `button.card.showcard > .jp + .ru`; значок «развернуть» справа рисуется сам. `.card.edit .preview` — белый превью-лист в любой теме.
- Полный экран: `#fs.fs > .fs-body > p.fs-line(.small) > .fs-ja`, `p.fs-caption`, `.fs-bar > .btn`. `.fs.rot` — ручной поворот на 90°.
- Размер текста: **[NEW]** задавать `--fs-n` — число, процент от короткой стороны: `style="--fs-n: 11"`. Старый `--fs: 11vmin` тоже работает. Рекомендуемая таблица по длине текста: ≤ 8 знаков — 20; ≤ 20 — 13.5; ≤ 40 — 11; ≤ 80 — 8; дальше 6. При 11 на экране 412 px знак около 45 px — читается с метра с запасом.
- Перенос строк: в Chrome 119+ японский рвётся по смысловым группам (`word-break: auto-phrase`), строки уравниваются (`text-wrap: balance`); Safari переносит обычным образом.
- Альбомная ориентация: панель кнопок уходит вбок, текст получает всю высоту (`shots/show-landscape-915x412-light.png`).

Блоки `section.block > h2.section`. **[NEW]** номера: `<a class="tel" href="tel:110"><b>110</b><span>Полиция</span></a>`; длинный номер — `<b class="long">`, вторая строка — `<small>`. `a.btn.danger` тоже оформлен.

## 6. Доступность

- Контраст — раздел 2: текст ≥ 4.5, границы и иконки ≥ 3 в обеих темах.
- Фокус: `:focus-visible` — контур 2 px цвета `--ai` с отступом 2 px; на карточке «показать» — чёрный. Мышиный/тач-фокус контур не рисует.
- Состояния никогда не передаются одним цветом: ○/×, мазок + подпись, `aria-pressed` у звезды, `aria-current` у вкладки.
- `lang="ja"` на всём японском (правильные глифы и голос скринридера), `rt` не попадает в выделение.
- Размеры в rem — системное увеличение шрифта работает.
- Поля 16 px — iOS Safari не зумит страницу при фокусе.

## 7. Движение

Сдержанно: нажатие 120 мс (сдвиг на 1 px и заливка), появление ответа и тоста 220 мс (прозрачность + 4–8 px), кривая `cubic-bezier(.2,.7,.2,1)`. Печать вкладки просто появляется. При `prefers-reduced-motion: reduce` все длительности — 1 мс, энсо загрузки не вращается, сдвиги отключены.

## 9. Интеграция для сборщика

**Путь Б (рекомендуемый) — заменить стили целиком.**
1. Скопировать `design/fonts/*.woff2` и `fonts.css` в `app/fonts/`, `design/icons/*.png` и `icon.svg` в `app/icons/`.
2. В `app/index.html` вместо `styles.css` подключить по порядку: `fonts/fonts.css`, `tokens.css`, `components.css` (или склеить в один `styles.css`; тогда в `fonts.css` поправить пути на `fonts/…`).
3. `<link rel="apple-touch-icon" href="icons/apple-touch-icon.png">`, в манифесте — три PNG, `background_color` и `theme_color` `#f5f1e7`; мета-теги из раздела 2.
4. Добавить в precache `sw.js` три woff2 и CSS; поднять `VERSION`.
5. Добавить `button.theme-toggle` в `header.top` и сниппет из раздела 2.
6. По желанию: `.is-collapsed` / `.open` для фраз, `--fs-n` для карточки, `.tel`, `.progress`, `.leitner`, иконки `.ico-*`, текст кнопки `0.7×`.

**Путь А (минимальный) — только токены.** Подключить `tokens.css` после `:root` в текущем `app/styles.css`: в нём есть алиасы всех переменных, которые этот файл использует (`--color-bg`, `--color-surface`, `--color-accent`, `--font-ja`, `--radius-*`, `--tap-min` …). Приложение получит бумагу, тушь и обе темы без остального; основная кнопка при этом будет красной, а не чёрной.

**Скрипты (`design/tools/`)**: `subset-fonts.py`, `make-icon.py`, `contrast.py`, `contact.py` — Python из локального `.venv`; `shots.mjs`, `render-icons.mjs`, `chrome.mjs` — Node 20 + установленный Chrome, без npm-зависимостей (скрипт сам перезапускается с `--experimental-websocket`).

**Не проверено на устройствах.** Скриншоты сняты в headless Chrome на Windows с эмуляцией 412×915 и 430×932 (DPR 2). Мелкий японский на них — Yu Gothic; на Pixel будет Noto Sans CJK JP, на iPhone — Hiragino Sans. Safe area, `backdrop-filter` таб-бара и `:has()` (нужен Safari 15.4+, Chrome 105+) стоит посмотреть на реальном iPhone и Pixel.
